## Folder map

- [`implementation-plans/`](./implementation-plans/) — main implementation plan and plan index.
- [`architecture/`](./architecture/) — technical architecture, module boundaries, data flow, stack decisions, market-data provider decisions, and full end-to-end architecture guidance.
- [`product/`](./product/) — PRD, product decisions, success metrics, user flows, detailed rule definitions, and chart annotation guidance.
- [`engineering/`](./engineering/) — recommended repository/file structure and implementation module contracts.
- [`qa/`](./qa/) — test cases, validation scenarios, and regression guidance.
- [`execution/`](./execution/) — Jira-ready issue breakdown, detailed Jira tickets, sprint plan, delivery sequencing, pricing, and launch planning.
- [`session-handoffs/`](./session-handoffs/) — continuity docs for fresh sessions.
- [`work-log/`](./work-log/) — concise summary of what has already been created and why.
